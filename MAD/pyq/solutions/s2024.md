## Q.1 (a) Give the significance of Bundle in Android App. [03]

=> **Bundle** is a key-value data structure used to pass and save data in Android.

### Significance

1. It passes data from one Activity to another using Intent extras.
2. It stores temporary Activity state during configuration changes.
3. It is used in lifecycle methods like `onCreate()` and `onSaveInstanceState()`.
4. It can store primitive values, strings, arrays and serializable objects.

### Example

```java
Intent intent = new Intent(this, SecondActivity.class);
Bundle bundle = new Bundle();
bundle.putString("name", "Aman");
bundle.putInt("age", 20);
intent.putExtras(bundle);
startActivity(intent);
```

## Q.1 (b) Demonstrate the use of Fragment with respect to Android App. [04]

=> **Fragment** is a reusable portion of an Activity UI. It has its own lifecycle and must be hosted inside an Activity.

### Uses

1. Reuse UI in multiple activities.
2. Create dynamic UI for different screen sizes.
3. Add, remove or replace UI parts at runtime.
4. Support tablet and phone layouts effectively.

### Example Fragment

```java
public class HomeFragment extends Fragment {
    @Override
    public View onCreateView(LayoutInflater inflater,
                             ViewGroup container,
                             Bundle savedInstanceState) {
        return inflater.inflate(R.layout.fragment_home, container, false);
    }
}
```

### Add fragment in Activity

```java
getSupportFragmentManager()
        .beginTransaction()
        .replace(R.id.container, new HomeFragment())
        .commit();
```

## Q.1 (c) List out different layouts available in Android and explain any three in detail. [07]

=> Layouts are ViewGroups used to arrange UI controls on the screen.

### Different layouts

1. LinearLayout
2. RelativeLayout
3. FrameLayout
4. TableLayout
5. GridLayout
6. ConstraintLayout
7. ScrollView

### 1. LinearLayout

=> Arranges child views in a single direction, either vertical or horizontal.

```xml
<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <TextView android:text="Name" />
    <EditText android:hint="Enter name" />
</LinearLayout>
```

### 2. RelativeLayout

=> Places views relative to parent or other views.

```xml
<RelativeLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <TextView
        android:id="@+id/title"
        android:layout_centerHorizontal="true"
        android:text="Login" />

    <Button
        android:layout_below="@id/title"
        android:layout_centerHorizontal="true"
        android:text="Submit" />
</RelativeLayout>
```

### 3. TableLayout

=> Arranges controls in rows and columns using `TableRow`.

```xml
<TableLayout
    android:layout_width="match_parent"
    android:layout_height="wrap_content">

    <TableRow>
        <TextView android:text="Email" />
        <EditText android:hint="Enter email" />
    </TableRow>

    <TableRow>
        <TextView android:text="Password" />
        <EditText android:inputType="textPassword" />
    </TableRow>
</TableLayout>
```

=> Layouts help create structured and responsive Android user interfaces.

## Q.2 (c) OR Explain Android activity life cycle. [07]

=> Activity lifecycle describes the states of an Activity from creation to destruction.

```text
onCreate() -> onStart() -> onResume()
                    |
              Activity Running
                    |
                onPause()
               /        \
        onResume()     onStop()
                          |
                    onRestart()
                          |
                      onStart()

Finish: onPause() -> onStop() -> onDestroy()
```

### Methods

1. `onCreate()` - called when Activity is first created.
2. `onStart()` - called when Activity becomes visible.
3. `onResume()` - called when Activity starts interacting with user.
4. `onPause()` - called when Activity loses focus.
5. `onStop()` - called when Activity is no longer visible.
6. `onRestart()` - called when stopped Activity starts again.
7. `onDestroy()` - called before Activity is destroyed.

### Example

```java
public class MainActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
    }

    @Override protected void onStart() { super.onStart(); }
    @Override protected void onResume() { super.onResume(); }
    @Override protected void onPause() { super.onPause(); }
    @Override protected void onStop() { super.onStop(); }
    @Override protected void onDestroy() { super.onDestroy(); }
}
```

## Q.3 (c) OR Demonstrate the use of Location services in Android with an example. [07]

=> Location services are used to get the current location of the device.

=> Android can get location using GPS provider, network provider or fused location provider.

### Required permission

```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

### Example Java code

```java
public class MainActivity extends AppCompatActivity {
    TextView txtLocation;
    LocationManager locationManager;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        txtLocation = findViewById(R.id.txtLocation);
        locationManager = (LocationManager) getSystemService(LOCATION_SERVICE);

        if (ActivityCompat.checkSelfPermission(this,
                Manifest.permission.ACCESS_FINE_LOCATION)
                != PackageManager.PERMISSION_GRANTED) {
            ActivityCompat.requestPermissions(this,
                    new String[]{Manifest.permission.ACCESS_FINE_LOCATION}, 1);
            return;
        }

        locationManager.requestLocationUpdates(
                LocationManager.GPS_PROVIDER,
                5000,
                5,
                location -> {
                    double lat = location.getLatitude();
                    double lng = location.getLongitude();
                    txtLocation.setText("Lat: " + lat + "\nLng: " + lng);
                });
    }
}
```

## Q.4 (c) OR Demonstrate the use of SQLite database in Android App with an example. [07]

=> SQLite is a lightweight relational database built into Android.

### DBHelper.java

```java
public class DBHelper extends SQLiteOpenHelper {
    public DBHelper(Context context) {
        super(context, "StudentDB", null, 1);
    }

    @Override
    public void onCreate(SQLiteDatabase db) {
        db.execSQL("CREATE TABLE student(" +
                "id INTEGER PRIMARY KEY AUTOINCREMENT," +
                "name TEXT," +
                "branch TEXT)");
    }

    @Override
    public void onUpgrade(SQLiteDatabase db, int oldVersion, int newVersion) {
        db.execSQL("DROP TABLE IF EXISTS student");
        onCreate(db);
    }

    public boolean insertStudent(String name, String branch) {
        SQLiteDatabase db = getWritableDatabase();
        ContentValues values = new ContentValues();
        values.put("name", name);
        values.put("branch", branch);

        long result = db.insert("student", null, values);
        return result != -1;
    }
}
```

### Use in Activity

```java
DBHelper dbHelper = new DBHelper(this);
boolean inserted = dbHelper.insertStudent("Aman", "Computer");

if (inserted) {
    Toast.makeText(this, "Data inserted", Toast.LENGTH_SHORT).show();
}
```

## Q.5 (c) OR What is the use of intent? Explain different types of intent with an example. [07]

=> Intent is used to communicate between Android components.

### Uses

1. Start Activity.
2. Start Service.
3. Send Broadcast.
4. Pass data between components.
5. Open system apps like browser, dialer and camera.

### Types

1. **Explicit Intent**

=> Specifies the exact target component.

```java
Intent intent = new Intent(MainActivity.this, SecondActivity.class);
intent.putExtra("name", "Aman");
startActivity(intent);
```

2. **Implicit Intent**

=> Specifies action but not exact target component.

```java
Intent intent = new Intent(Intent.ACTION_DIAL);
intent.setData(Uri.parse("tel:9876543210"));
startActivity(intent);
```

### Difference

| Explicit Intent | Implicit Intent |
|---|---|
| Target component is known. | Target component is not known. |
| Used inside same app. | Used to call other apps/system apps. |
| Example: Open SecondActivity. | Example: Open dialer/browser. |
