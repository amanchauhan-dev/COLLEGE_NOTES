## Q.1 (a) List out the basic features of MongoDB. [03]

=> **MongoDB** is a NoSQL document-oriented database. It stores data in BSON format, which is similar to JSON.

### Basic features

1. **Document-oriented storage**
=> Data is stored as documents instead of rows and columns.

2. **Flexible schema**
=> Documents in the same collection may have different fields.

3. **Indexing**
=> Indexes improve searching speed.

4. **Replication**
=> Copies of data can be maintained on multiple servers for high availability.

5. **Sharding**
=> Large data can be distributed across multiple servers.

6. **High performance**
=> MongoDB is fast for read/write operations in modern web applications.

## Q.1 (c) What is CSS? Explain different types of CSS. List advantages and disadvantages. [07]

=> **CSS** stands for **Cascading Style Sheets**.

=> CSS is used to style HTML pages. It controls color, font, border, spacing, alignment, layout and responsiveness.

### Types of CSS

1. **Inline CSS**

```html
<p style="color:red; font-size:18px;">Inline CSS</p>
```

=> Written inside an HTML tag. It is useful for quick styling but not recommended for large websites.

2. **Internal CSS**

```html
<style>
p {
  color: blue;
}
</style>
```

=> Written inside the `<style>` tag in the same HTML page.

3. **External CSS**

```html
<link rel="stylesheet" href="style.css">
```

```css
p {
  color: green;
}
```

=> Written in a separate file. It is best for large websites.

### Advantages

1. Separates content and design.
2. Saves time through reusable styles.
3. Improves consistency across pages.
4. Makes maintenance easy.
5. Supports responsive design.

### Disadvantages

1. Browser compatibility issues may occur.
2. CSS priority/specificity can create confusion.
3. Large CSS files may become difficult to manage.
4. Incorrect CSS can break page layout.

## Q.2 (c OR) Explain Node JS streams in detail. [07]

=> **Stream** is an object used to read or write data continuously in small chunks.

=> Streams are memory efficient because they do not load the entire file into memory.

### Types of streams

| Type | Explanation |
|---|---|
| Readable | Reads data from source |
| Writable | Writes data to destination |
| Duplex | Can read and write both |
| Transform | Modifies data while reading/writing |

### Common stream events

1. `data`: Fired when a chunk is available.
2. `end`: Fired when reading is complete.
3. `error`: Fired when error occurs.
4. `finish`: Fired when writing is complete.

```js
const fs = require("fs");

const read = fs.createReadStream("input.txt", "utf8");
const write = fs.createWriteStream("output.txt");

read.on("data", function(chunk) {
  console.log("Chunk:", chunk);
});

read.on("end", function() {
  console.log("Reading completed");
});

read.pipe(write);
```

=> `pipe()` sends data from readable stream to writable stream.

## Q.3 (c) Explain use of `ng-controller` directive with example. [07]

=> `ng-controller` directive attaches a controller to a section of HTML.

=> Controller contains application logic and provides data/functions to the view using `$scope`.

```html
<!DOCTYPE html>
<html ng-app="app">
<body ng-controller="StudentCtrl">
  <h3>{{title}}</h3>
  <input ng-model="student.name">
  <button ng-click="show()">Show</button>
  <p>{{message}}</p>

  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script>
  var app = angular.module("app", []);

  app.controller("StudentCtrl", function($scope) {
    $scope.title = "Student Information";
    $scope.student = { name: "Aman" };

    $scope.show = function() {
      $scope.message = "Hello " + $scope.student.name;
    };
  });
  </script>
</body>
</html>
```

=> Here `StudentCtrl` controls the view and `$scope` shares data between controller and HTML.

## Q.3 (c OR) Explain Node JS event-driven programming with example. [07]

=> In **event-driven programming**, program execution depends on events.

=> Node JS uses event loop and callbacks to handle events such as client requests, file read completion and custom events.

```js
const EventEmitter = require("events");
const event = new EventEmitter();

event.on("login", function(user) {
  console.log(user + " logged in");
});

event.on("logout", function(user) {
  console.log(user + " logged out");
});

event.emit("login", "Aman");
event.emit("logout", "Aman");
```

### Explanation

1. `EventEmitter` class is imported from `events` module.
2. `on()` registers an event listener.
3. `emit()` triggers the event.
4. Callback function runs when event occurs.

=> Event-driven programming makes Node JS suitable for scalable network applications.

## Q.4 (b) Justify “Node.js Single-threaded”. [04]

=> Node.js executes JavaScript code on a single main thread.

=> It does not create a new thread for every request like traditional servers. Instead, it uses an event loop and non-blocking I/O.

### Explanation

1. Request comes to Node.js server.
2. If it is simple JavaScript work, it executes on main thread.
3. If it is I/O work, Node.js starts the operation asynchronously.
4. Callback runs when operation completes.

=> This makes Node.js efficient for I/O-heavy applications such as APIs, chat apps and streaming apps.

## Q.4 (c) Insert, find and delete data in collection using NodeJS-MongoDB. [07]

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");

  try {
    await client.connect();
    const col = client.db("college").collection("students");

    await col.insertOne({ rollno: 1, name: "Aman", branch: "CE" });
    await col.insertOne({ rollno: 2, name: "Ravi", branch: "IT" });

    const result = await col.find({}).toArray();
    console.log("Students:", result);

    await col.deleteOne({ rollno: 1 });
    console.log("Document deleted");
  } catch (err) {
    console.log("Error:", err.message);
  } finally {
    await client.close();
  }
}

main();
```

=> `insertOne()` inserts a document, `find()` retrieves documents and `deleteOne()` deletes first matching document.

## Q.4 (c OR) Demonstrate the use of `ng-route` directive with example. [07]

=> AngularJS routing is used to display different views in a single page application.

```html

<html ng-app="app">

  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
```

## Q.5 (b) JavaScript program to check whether given number is prime or not. [04]

```js
let n = 17;
let isPrime = true;

if (n <= 1) {
  isPrime = false;
} else {
  for (let i = 2; i <= Math.sqrt(n); i++) {
    if (n % i === 0) {
      isPrime = false;
      break;
    }
  }
}

console.log(isPrime ? "Prime Number" : "Not Prime Number");
```

=> A prime number is divisible only by 1 and itself.

## Q.5 (c) Explain Node JS buffers in detail. [07]

=> **Buffer** is a temporary memory area used to store binary data in Node.js.

=> JavaScript normally handles strings easily, but binary data such as files, images and network packets are handled using Buffer.

### Creating Buffer

```js
const b1 = Buffer.alloc(10);
const b2 = Buffer.from("Hello");
const b3 = Buffer.from([65, 66, 67]);

console.log(b1);
console.log(b2.toString());
console.log(b3.toString());
```

### Important methods

| Method | Use |
|---|---|
| `Buffer.alloc(size)` | Creates buffer of given size |
| `Buffer.from(data)` | Creates buffer from string/array |
| `toString()` | Converts buffer to string |
| `write()` | Writes data into buffer |
| `length` | Returns buffer size |

=> Buffers are commonly used with file system, streams and TCP communication.

## Q.5 (c OR) Explain how to read a file using Node and create a directory. [07]

```js
const fs = require("fs");

fs.readFile("data.txt", "utf8", function(err, data) {
  if (err) {
    console.log("Read Error:", err.message);
    return;
  }
  console.log("File Content:", data);
});

fs.mkdir("myfolder", { recursive: true }, function(err) {
  if (err) {
    console.log("Directory Error:", err.message);
    return;
  }
  console.log("Directory created successfully");
});
```

=> `fs.readFile()` reads file content asynchronously. `fs.mkdir()` creates a directory. The `{ recursive: true }` option avoids error if parent directories need to be created.
