## Q.1 (c) What is CSS? Explain types, advantages and disadvantages. [07]

### Types

```html
<p style="color:red">Inline CSS</p>
<style>p { color: blue; }</style>
<link rel="stylesheet" href="style.css">
```

### Advantages

1. Separates content and design.
2. Saves time using reusable styles.
3. Improves consistency.
4. Makes maintenance easy.

### Disadvantages

## Q.2 (c OR) Explain Node JS streams in detail. [07]

=> Stream processes data in chunks.

### Types

1. Readable stream.
2. Writable stream.
3. Duplex stream.
4. Transform stream.

```js
const fs = require("fs");

```

=> Streams are memory efficient for large files.

## Q.3 (b) Explain REPL and var difference in REPL. [04]

## Q.3 (c) Explain `ng-controller` with example. [07]

## Q.3 (c OR) Explain Node JS event-driven programming. [07]


## Q.4 (b) Justify Node.js single-threaded. [04]

=> Node JS runs JavaScript code on a single main thread.

=> It uses an event loop and non-blocking I/O to handle many requests. Heavy I/O work is delegated internally, and callbacks run when operations complete.

=> This makes Node JS suitable for scalable I/O-based applications.

## Q.4 (c) Insert, find and delete data using NodeJS-MongoDB. [07]

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");
  await client.connect();
  const col = client.db("college").collection("students");

  await col.insertOne({ rollno: 1, name: "Aman" });
  console.log(await col.find({}).toArray());
  await col.deleteOne({ rollno: 1 });

  await client.close();
}
main();
```

## Q.4 (b OR) Explain two data models of MongoDB. [04]

## Q.4 (c OR) Demonstrate `ng-route` directive with example. [07]

```html
  <a href="#!/">Home</a>
  <a href="#!/about">About</a>
  <div ng-view></div>
</div>

var app = angular.module("app", ["ngRoute"]);

});
</script>
```

## Q.5 (b) JavaScript program to check prime number. [04]

```js
let n = 17;
let prime = n > 1;

for (let i = 2; i <= Math.sqrt(n); i++) {
  if (n % i === 0) {
    prime = false;
    break;
  }
}
console.log(prime ? "Prime" : "Not Prime");
```

## Expanded Exam-Writing Points

### Q.1 Revision Points

=> MongoDB should be explained as a document-oriented NoSQL database. Instead of storing rows and columns, it stores documents inside collections.

=> Important MongoDB terms are database, collection, document, field and `_id`. The `_id` field uniquely identifies each document.

=> While discussing JavaScript advantages, write that JavaScript improves interactivity through DOM manipulation, form validation, event handling and AJAX.

=> While discussing JavaScript disadvantages, mention that client-side JavaScript cannot be trusted for security because users can view or modify browser-side code.

=> CSS answer should include examples of inline, internal and external CSS. For 7 marks, also explain cascading priority, reusability and browser compatibility.

### Q.2 Revision Points

=> CSS basic selectors are used most frequently in exams. Element selector selects tags, class selector selects reusable groups, ID selector selects one unique element and universal selector selects all elements.

=> AngularJS and Node.js are both JavaScript-related, but their purpose is different. AngularJS is mainly for client-side UI and Node.js is mainly for server-side programming.

=> DOM answer should include DOM tree, element access methods and modification methods. Write that DOM allows JavaScript to change content, style and attributes after page loading.

=> For Node.js streams, explain that streams are event-based. Common events are `data`, `end`, `error` and `finish`.

### Q.3 Revision Points

=> Client-side scripting runs in the browser and is useful for validation, UI changes and user interaction. Server-side scripting runs on the server and handles database, authentication and business logic.

=> REPL means Read, Eval, Print, Loop. It reads input, evaluates it, prints output and waits for next input.

=> `ng-controller` connects controller logic with a particular part of HTML. The controller commonly uses `$scope` to expose variables and functions to the view.

=> AngularJS module should be described as the root container of an AngularJS application. It avoids polluting the global namespace and groups related controllers, services and filters.

=> Event-driven programming in Node.js means program flow depends on events. Server request, file read completion and custom events can trigger callback execution.

### Q.4 Revision Points

=> AngularJS services are singleton objects. They help share code between controllers and avoid repeated logic.

=> Node.js is called single-threaded because JavaScript execution happens on one main thread. Still, it handles many concurrent requests using non-blocking I/O and event loop.

=> MongoDB insert, find and delete operations should mention collection methods: `insertOne()`, `insertMany()`, `find()`, `findOne()`, `deleteOne()` and `deleteMany()`.

=> Bootstrap provides predefined CSS classes. It is mainly used for responsive grid, buttons, forms, tables, navbar and cards.

=> MongoDB embedded model stores related data in one document. Referenced model stores related data in different collections and links them using id.

### Q.5 Revision Points

=> Asynchronous API returns immediately and completes work later. This improves performance when operations take time, such as database queries or file reading.

=> Prime number program should handle values less than or equal to 1 because they are not prime.

=> Buffer is a fixed-size memory area used to handle binary data. `Buffer.from()` creates buffer from string or array, and `Buffer.alloc()` creates a buffer of specified size.

=> AngularJS expressions are written using `{{ }}` and are evaluated against AngularJS scope. They should be used for simple output, not complex business logic.

=> For file and directory operations, always mention that `fs` module provides both synchronous and asynchronous methods. Asynchronous methods are preferred in Node.js server applications.
