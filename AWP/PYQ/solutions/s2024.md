## Q.1 (c) Explain different types of CSS with examples and advantages. [07]

=> CSS is used to style HTML pages.

### 1. Inline CSS

```html
<p style="color:red">Hello</p>
```

=> Applied directly to an element. It has high priority but is difficult to maintain.

### 2. Internal CSS

```html
<style>
p { color: blue; font-size: 18px; }
</style>
```

=> Written inside the same HTML file. Useful for single-page styling.

### 3. External CSS

```html
<link rel="stylesheet" href="style.css">
```

```css
p {
  color: green;
}
```

### Advantages

1. Separates design from content.
2. Saves development time.
3. Improves consistency.
4. External CSS can be reused.
5. Pages become easier to maintain.

## Q.2 (c) Discuss MVC architecture in AngularJS with example. [07]

=> MVC divides application into Model, View and Controller.

```html
<div ng-app="app" ng-controller="Ctrl">
  <input ng-model="student.name">
  <p>{{student.name}}</p>
</div>
<script>
var app = angular.module("app", []);

```

=> `student` is model, HTML is view and `Ctrl` is controller. AngularJS binding keeps model and view synchronized.

## Q.2 (c OR) Write a JavaScript program for password verification. [07]

```html
<input type="password" id="pwd">
<button onclick="check()">Check</button>
<p id="msg"></p>

<script>
function check() {
  let p = document.getElementById("pwd").value;
  let pattern = /^(?=.*[A-Z])(?=.*[a-z])(?=.*\d).{8,}$/;
  if (pattern.test(p)) {
    document.getElementById("msg").innerHTML = "Valid password";
  } else {
    document.getElementById("msg").innerHTML =
      "Password must contain uppercase, lowercase, digit and minimum 8 characters";
  }
}
</script>
```

## Q.4 (c) Explain callbacks in Node JS with example. [07]

=> Callback is a function passed to another function and executed after an operation completes.

```js
const fs = require("fs");

fs.readFile("data.txt", "utf8", function(err, data) {
  if (err) {
    console.log("Error:", err.message);
    return;
  }
  console.log(data);
});

console.log("File reading started");
```

=> Callback helps Node JS perform non-blocking operations like file reading and database access.

## Q.5 (c) Explain delete operations using Node JS and MongoDB. [07]

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");
  await client.connect();
  const col = client.db("college").collection("students");

  await col.deleteOne({ rollno: 1 });
  await col.deleteMany({ branch: "CE" });

  console.log("Documents deleted");
  await client.close();
}
main();
```

=> `deleteOne()` deletes first matching document and `deleteMany()` deletes all matching documents.

## Q.5 (c OR) Discuss routing configuration using AngularJS. [07]

```html
<div ng-app="app">
  <a href="#!/">Home</a>
  <a href="#!/about">About</a>
  <div ng-view></div>
</div>
<script>
var app = angular.module("app", ["ngRoute"]);
app.config(function($routeProvider) {
  $routeProvider
    .when("/", { template: "<h2>Home</h2>" })
    .when("/about", { template: "<h2>About</h2>" })
    .otherwise({ redirectTo: "/" });
});
</script>
```

=> `ngRoute`, `$routeProvider` and `ng-view` are the main parts of AngularJS routing.
