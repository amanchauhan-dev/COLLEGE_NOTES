## Q.1 (c) Explain different types of CSS with examples and advantages. [07]

=> CSS is used to style HTML pages and separate presentation from content.

### 1. Inline CSS

```html
<p style="color:red; font-size:18px;">Inline CSS</p>
```

=> Written inside HTML tag. It is useful for quick styling but difficult to maintain.

### 2. Internal CSS

```html
<style>
p {
  color: blue;
}
</style>
```

=> Written inside `<style>` tag in the same HTML file.

### 3. External CSS

```html
<link rel="stylesheet" href="style.css">
```

```css
p {
  color: green;
}
```

=> Written in a separate file and linked with HTML. It is best for large websites.

### Advantages of CSS

1. Separates content and design.
2. Saves time by reusing styles.
3. Improves consistency across pages.
4. Makes maintenance easy.
5. Supports responsive design.

## Q.2 (c) Discuss MVC architecture in AngularJS with example. [07]

=> **MVC** stands for **Model View Controller**.

| Component | Meaning in AngularJS |
|---|---|
| Model | Data stored in `$scope` |
| View | HTML page |
| Controller | JavaScript function controlling view |

```html
<!DOCTYPE html>
<html ng-app="app">
<body ng-controller="StudentCtrl">
  <h3>{{title}}</h3>
  <input ng-model="student.name">
  <p>Student Name: {{student.name}}</p>

  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script>
  var app = angular.module("app", []);
  app.controller("StudentCtrl", function($scope) {
    $scope.title = "MVC Example";
    $scope.student = { name: "Aman" };
  });
  </script>
</body>
</html>
```

=> `student` is model, HTML is view and `StudentCtrl` is controller.

## Q.2 (c OR) JavaScript program for password verification. [07]

=> Password verification checks whether password satisfies required conditions.

### Conditions

1. Minimum 8 characters.
2. At least one uppercase letter.
3. At least one lowercase letter.
4. At least one digit.

```html
<!DOCTYPE html>
<html>
<body>
  <input type="password" id="pwd" placeholder="Enter Password">
  <button onclick="checkPassword()">Check</button>
  <p id="msg"></p>

  <script>
  function checkPassword() {
    let pwd = document.getElementById("pwd").value;
    let pattern = /^(?=.*[A-Z])(?=.*[a-z])(?=.*\d).{8,}$/;

    if (pattern.test(pwd)) {
      document.getElementById("msg").innerHTML = "Valid Password";
    } else {
      document.getElementById("msg").innerHTML =
        "Password must contain uppercase, lowercase, digit and minimum 8 characters";
    }
  }
  </script>
</body>
</html>
```

## Q.4 (c) Explain callbacks in Node JS with example. [07]

=> Callback is a function passed as an argument to another function and executed later.

=> Node JS uses callbacks heavily for asynchronous operations.

```js
const fs = require("fs");

console.log("Before reading file");

fs.readFile("data.txt", "utf8", function(err, data) {
  if (err) {
    console.log("Error:", err.message);
    return;
  }
  console.log("File Data:", data);
});

console.log("After reading file");
```

### Explanation

1. `readFile()` starts file reading.
2. Node JS does not wait and executes next statement.
3. Callback runs when file reading completes.
4. First callback parameter handles error.

## Q.4 (c OR) Explain EventEmitter with suitable example. [07]

=> `EventEmitter` is a class from Node JS `events` module used to create custom events.

```js
const EventEmitter = require("events");
const event = new EventEmitter();

event.on("message", function(msg) {
  console.log("Message received:", msg);
});

event.once("start", function() {
  console.log("Started once");
});

event.emit("start");
event.emit("start");

=> `on()` registers listener, `emit()` triggers event and `once()` runs listener only one time.

## Q.5 (b) Discuss connection operations between Node JS and MongoDB. [04]

=> Node JS connects with MongoDB using the `mongodb` driver.

### Steps

1. Install MongoDB driver using `npm install mongodb`.

4. Select database and collection.
5. Perform database operations.
6. Close connection.

const { MongoClient } = require("mongodb");
const client = new MongoClient("mongodb://127.0.0.1:27017");

async function connectDB() {
  await client.connect();
  const db = client.db("college");
  return db.collection("students");
}
```

## Q.5 (c) Explain delete database operations using Node JS and MongoDB. [07]

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");

  try {
    await client.connect();
    const col = client.db("college").collection("students");

    await col.deleteOne({ rollno: 1 });
    await col.deleteMany({ branch: "CE" });

    console.log("Delete operations completed");
  } catch (err) {
    console.log("Error:", err.message);
  } finally {
    await client.close();
  }
}

main();
```

=> `deleteOne()` deletes first matching document. `deleteMany()` deletes all documents matching the condition.

## Q.5 (c OR) Discuss routing configuration using AngularJS. [07]

```html
<!DOCTYPE html>
<html ng-app="app">
<head>
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular-route.js"></script>
</head>
<body>
  <a href="#!/">Home</a>
  <a href="#!/about">About</a>
  <div ng-view></div>

  <script>
  var app = angular.module("app", ["ngRoute"]);
  app.config(function($routeProvider) {
    $routeProvider
      .when("/", { template: "<h2>Home</h2>" })
      .when("/about", { template: "<h2>About</h2>" })
      .otherwise({ redirectTo: "/" });
  });
  </script>
</body>
</html>
```

=> `ngRoute` provides routing, `$routeProvider` configures URL paths and `ng-view` displays selected template.
