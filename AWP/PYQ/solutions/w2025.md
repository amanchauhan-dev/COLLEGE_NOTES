## Q.1 (a) Describe Selectors in CSS. [03]

=> **CSS selector** is used to select HTML elements on which style rules are applied.

| Selector | Example | Use |
|---|---|---|
| Element | `p { color: red; }` | Selects all `<p>` tags |
| Class | `.box { border: 1px solid black; }` | Selects elements with `class="box"` |
| ID | `#main { width: 80%; }` | Selects element with `id="main"` |
| Universal | `* { margin: 0; }` | Selects all elements |
| Attribute | `input[type="text"] {}` | Selects elements by attribute |

## Q.1 (b) Explain DOM in detail. [04]

=> **DOM** stands for **Document Object Model**.

=> It represents an HTML document as a tree of objects so JavaScript can access and modify page content, style and structure.

```text
document
  |
  html
  |-- head
  |-- body
      |-- h1
      |-- p
      |-- button
```

### Common DOM methods

1. `getElementById()` selects an element using id.
2. `getElementsByClassName()` selects elements using class name.
3. `getElementsByTagName()` selects elements using tag name.
4. `querySelector()` selects the first matching CSS selector.
5. `querySelectorAll()` selects all matching CSS selectors.

```html
<p id="msg">Hello</p>
<script>
document.getElementById("msg").innerHTML = "Welcome";
</script>
```


## Q.4 (b) Write a note on Streams. [04]

=> **Stream** is used to handle data piece by piece instead of loading complete data into memory.

### Types of streams

1. **Readable**: Reads data, example file read stream.
2. **Writable**: Writes data, example file write stream.
3. **Duplex**: Can read and write both.
4. **Transform**: Modifies data while reading or writing.

```js
rs.on("data", chunk => console.log(chunk));
```

## Q.4 (c) Explain event-driven programming with example. [07]

=> In **event-driven programming**, program flow depends on events such as request, click, file read completion or custom event.

=> Node JS uses an event loop and callback functions to handle events asynchronously.

```js
const EventEmitter = require("events");
const emitter = new EventEmitter();

emitter.on("login", function(user) {
  console.log(user + " logged in");
});

emitter.emit("login", "Aman");
```

### Explanation

1. `EventEmitter` is imported from the `events` module.
2. `on()` registers an event listener.
3. `emit()` fires the event.
4. Callback function executes when event occurs.

=> This model is useful for servers because many client requests can be handled without blocking.

## Q.4 (b OR) Blocking and non-blocking code in NodeJS. [04]

| Blocking | Non-blocking |
|---|---|
| Executes synchronously | Executes asynchronously |
| Next statement waits | Next statement does not wait |
| Can reduce performance | Better for server applications |

```js
const fs = require("fs");

// Blocking
const data = fs.readFileSync("a.txt", "utf8");
console.log(data);

// Non-blocking
fs.readFile("a.txt", "utf8", function(err, data) {
  if (err) throw err;
  console.log(data);
});
console.log("This prints before async file data");
```

## Q.4 (c OR) Node JS file upload application. [07]

```js
const http = require("http");
const formidable = require("formidable");
const fs = require("fs");

http.createServer(function(req, res) {
  if (req.url === "/upload" && req.method.toLowerCase() === "post") {
    const form = new formidable.IncomingForm();
    form.uploadDir = "uploads";
    form.keepExtensions = true;

    form.parse(req, function(err, fields, files) {
      if (err) throw err;
      res.end("File uploaded successfully");
    });
    return;
  }

  res.writeHead(200, {"Content-Type": "text/html"});
  res.end(`
    <form action="/upload" method="post" enctype="multipart/form-data">
      <input type="file" name="file">
      <input type="submit" value="Upload">
    </form>
  `);
}).listen(8080);
```

=> Install module using `npm install formidable` and create an `uploads` directory.

## Q.5 (c) Node JS application for file operations. [07]

```js

fs.writeFile("demo.txt", "Hello AWP", function(err) {
```

## Q.5 (c OR) Explain CRUD Operation in MongoDB with example. [07]

```js
const { MongoClient } = require("mongodb");
const url = "mongodb://127.0.0.1:27017";

async function main() {
  const client = new MongoClient(url);
  await client.connect();
  const db = client.db("college");
  const students = db.collection("students");

  await students.insertOne({ rollno: 1, name: "Aman" });
  console.log(await students.find({}).toArray());

  await students.updateOne(
    { rollno: 1 },
    { $set: { name: "Aman Patel" } }
  );

  await students.deleteOne({ rollno: 1 });
  await client.close();
}

main();
```

=> CRUD means Create, Read, Update and Delete. MongoDB performs these operations using `insertOne()`, `find()`, `updateOne()` and `deleteOne()`.
