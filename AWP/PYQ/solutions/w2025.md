## Q.1 (a) Describe Selectors in CSS. [03]

=> **CSS selector** is used to select HTML elements on which CSS style rules are applied.

=> Selectors are important because they decide which element will receive which design.

| Selector | Example | Explanation |
|---|---|---|
| Element selector | `p { color: red; }` | Selects all `<p>` tags |
| Class selector | `.box { padding: 10px; }` | Selects all elements having `class="box"` |
| ID selector | `#main { width: 80%; }` | Selects element having `id="main"` |
| Universal selector | `* { margin: 0; }` | Selects all elements |
| Attribute selector | `input[type="text"] {}` | Selects elements by attribute |
| Group selector | `h1, p { color: blue; }` | Applies same style to multiple selectors |

```html
<style>
p { color: blue; }
.highlight { background: yellow; }
#title { color: red; }
</style>

<h1 id="title">AWP</h1>
<p class="highlight">CSS selector example</p>
```

## Q.1 (b) Explain DOM in detail. [04]

=> **DOM** stands for **Document Object Model**.

=> DOM represents an HTML document as a tree of objects. JavaScript can use this tree to access, modify, add or delete HTML elements.

### DOM tree

```text
document
  |
  html
  |-- head
  |   |-- title
  |
  |-- body
      |-- h1
      |-- p
      |-- button
```

### Common DOM methods

| Method | Use |
|---|---|
| `getElementById()` | Selects element by id |
| `getElementsByClassName()` | Selects elements by class |
| `getElementsByTagName()` | Selects elements by tag name |
| `querySelector()` | Selects first matching CSS selector |
| `querySelectorAll()` | Selects all matching CSS selectors |

```html
<p id="msg">Old Message</p>
<script>
document.getElementById("msg").innerHTML = "New Message";
</script>
```

=> DOM is useful for validation messages, dynamic content, event handling and style changes.

## Q.1 (c) JavaScript program for Array functions. [07]

=> JavaScript Array object provides built-in methods to search, sort and reverse array elements.

### Program

```html
<!DOCTYPE html>
<html>
<body>
<h3>Array Functions</h3>
<pre id="out"></pre>

<script>
let fruits = ["Mango", "Apple", "Banana", "Apple", "Orange"];
let result = "";

result += "Original Array: " + fruits + "\n";
result += "indexOf('Apple'): " + fruits.indexOf("Apple") + "\n";
result += "lastIndexOf('Apple'): " + fruits.lastIndexOf("Apple") + "\n";
result += "includes('Banana'): " + fruits.includes("Banana") + "\n";

fruits.sort();
result += "After sort(): " + fruits + "\n";

fruits.reverse();
result += "After reverse(): " + fruits + "\n";

document.getElementById("out").textContent = result;
</script>
</body>
</html>
```

### Explanation

1. `indexOf()` returns first index of given element.
2. `lastIndexOf()` returns last index of given element.
3. `includes()` returns true if element exists.
4. `sort()` arranges array elements.
5. `reverse()` reverses array order.

## Q.2 (b) Create an example demonstrating AngularJS Routing. [04]

=> AngularJS routing loads different views in the same page without full refresh.

```html
<!DOCTYPE html>
<html ng-app="myApp">
<head>
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular-route.js"></script>
</head>
<body>
  <a href="#!/">Home</a>
  <a href="#!/about">About</a>
  <div ng-view></div>

  <script>
  var app = angular.module("myApp", ["ngRoute"]);
  app.config(function($routeProvider) {
    $routeProvider
      .when("/", { template: "<h2>Home Page</h2>" })
      .when("/about", { template: "<h2>About Page</h2>" })
      .otherwise({ redirectTo: "/" });
  });
  </script>
</body>
</html>
```

=> `ngRoute` enables routing, `$routeProvider` defines routes and `ng-view` displays the selected view.

## Q.4 (c) Explain event-driven programming in detail with example. [07]

=> In **event-driven programming**, program flow depends on events.

=> Node JS uses event loop and callbacks to handle events such as client requests, file read completion and custom events.

```js
const EventEmitter = require("events");
const emitter = new EventEmitter();

emitter.on("login", function(user) {
  console.log(user + " logged in");
});

emitter.on("logout", function(user) {
  console.log(user + " logged out");
});

emitter.emit("login", "Aman");
emitter.emit("logout", "Aman");
```

### Explanation

1. `EventEmitter` class is imported.
2. `on()` registers event listeners.
3. `emit()` fires an event.
4. Callback executes when event occurs.

=> Event-driven model makes Node JS suitable for scalable server applications.

## Q.4 (b OR) Blocking and non-blocking code using NodeJS example. [04]

| Blocking code | Non-blocking code |
|---|---|
| Executes synchronously | Executes asynchronously |
| Next statement waits | Next statement does not wait |
| Slower for many requests | Better for server apps |

```js
const fs = require("fs");

// Blocking
const data = fs.readFileSync("a.txt", "utf8");
console.log(data);

// Non-blocking
fs.readFile("a.txt", "utf8", function(err, data) {
  if (err) throw err;
  console.log(data);
});

console.log("This line runs before async file data");
```

## Q.4 (c OR) Node JS application to browse and upload a file in localhost. [07]

```js
const http = require("http");
const formidable = require("formidable");
const fs = require("fs");
const path = require("path");

http.createServer(function(req, res) {
  if (req.url === "/upload" && req.method.toLowerCase() === "post") {
    const form = new formidable.IncomingForm();

    form.parse(req, function(err, fields, files) {
      if (err) throw err;

      const file = files.file[0] || files.file;
      const oldPath = file.filepath;
      const newPath = path.join(__dirname, "uploads", file.originalFilename);

      fs.rename(oldPath, newPath, function(err) {
        if (err) throw err;
        res.end("File uploaded successfully");
      });
    });
    return;
  }

  res.writeHead(200, {"Content-Type": "text/html"});
  res.end(`
    <form action="/upload" method="post" enctype="multipart/form-data">
      <input type="file" name="file">
      <input type="submit" value="Upload">
    </form>
  `);
}).listen(8080);
```

=> Install package using `npm install formidable` and create an `uploads` folder.

## Q.5 (c OR) Explain CRUD operation in MongoDB with example. [07]

=> CRUD means **Create, Read, Update and Delete**.

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");

  try {
    await client.connect();
    const db = client.db("college");
    const students = db.collection("students");

    // Create
    await students.insertOne({ rollno: 1, name: "Aman", branch: "CE" });

    // Read
    const result = await students.find({}).toArray();
    console.log(result);

    // Update
    await students.updateOne(
      { rollno: 1 },
      { $set: { name: "Aman Patel" } }
    );

    // Delete
    await students.deleteOne({ rollno: 1 });
  } catch (err) {
    console.log("Error:", err.message);
  } finally {
    await client.close();
  }
}

main();
```

=> MongoDB performs CRUD using methods like `insertOne()`, `find()`, `updateOne()` and `deleteOne()`.
