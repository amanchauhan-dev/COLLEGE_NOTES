## Q.1 (a) What is DOM? State the usefulness of DOM in JavaScript. [03]

## Q.1 (c) What is MVC? Explain how MVC can be used with AngularJS application. [07]

=> **MVC** stands for **Model View Controller**.

=> MVC is an architecture pattern that separates application into three parts.

| Part | Meaning |
|---|---|
| Model | Stores application data |
| View | Displays data to user |
| Controller | Handles logic and connects model with view |

### MVC in AngularJS

=> In AngularJS, model is usually represented by `$scope` variables, view is HTML page, and controller is JavaScript function.

```html
<!DOCTYPE html>
<html ng-app="studentApp">
<body ng-controller="StudentCtrl">
  <h3>{{title}}</h3>

  Name: <input ng-model="student.name">
  Branch: <input ng-model="student.branch">

  <p>Name: {{student.name}}</p>
  <p>Branch: {{student.branch}}</p>

  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script>
  var app = angular.module("studentApp", []);

  app.controller("StudentCtrl", function($scope) {
    $scope.title = "Student MVC Application";
    $scope.student = {
      name: "Aman",
      branch: "CE"
    };
  });
  </script>
</body>
</html>
```

### Explanation

1. `student` object is the model.
2. HTML page is the view.
3. `StudentCtrl` is the controller.
4. `ng-model` provides two-way binding between input and model.

## Q.2 (c) Explain AngularJS routing with suitable example. [07]

=> **Routing** in AngularJS is used to create single page applications where different views are loaded without refreshing the full page.

### Main routing parts

1. `ngRoute` module.
2. `$routeProvider` service.
3. `ng-view` directive.
4. Route links using `#!`.

```html
<!DOCTYPE html>
<html ng-app="myApp">
<head>
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular-route.js"></script>
</head>
<body>
  <a href="#!/">Home</a>
  <a href="#!/about">About</a>
  <div ng-view></div>

  <script>
  var app = angular.module("myApp", ["ngRoute"]);
  app.config(function($routeProvider) {
    $routeProvider
      .when("/", {
        template: "<h2>Home Page</h2><p>Welcome to AWP.</p>"
      })
      .when("/about", {
        template: "<h2>About Page</h2><p>This is AngularJS routing.</p>"
      })
      .otherwise({ redirectTo: "/" });
  });
  </script>
</body>
</html>
```

=> `ng-view` displays the selected route template.

## Q.3 (c OR) Node JS file upload in `Uploads` directory. [07]

```js
const http = require("http");
const formidable = require("formidable");
const fs = require("fs");
const path = require("path");

http.createServer(function(req, res) {
  if (req.url === "/upload" && req.method === "POST") {
    const form = new formidable.IncomingForm();

    form.parse(req, function(err, fields, files) {
      if (err) throw err;

      const file = files.file[0] || files.file;
      const oldPath = file.filepath;
      const newPath = path.join(__dirname, "Uploads", file.originalFilename);

      fs.rename(oldPath, newPath, function(err) {
        if (err) throw err;
        res.end("File uploaded successfully");
      });
    });
    return;
  }

  res.writeHead(200, {"Content-Type": "text/html"});
  res.end(`
    <form action="/upload" method="post" enctype="multipart/form-data">
      <input type="file" name="file">
      <button type="submit">Upload</button>
    </form>
  `);
}).listen(8080);
```

=> Install package using `npm install formidable` and create an `Uploads` folder.

## Q.4 (c OR) What is EventEmitter? Explain any three methods. [07]

=> `EventEmitter` is a class from Node JS `events` module used to create and handle custom events.

### Methods

| Method | Use |
|---|---|
| `on()` | Registers event listener |
| `emit()` | Triggers event |
| `once()` | Runs listener only once |
| `removeListener()` | Removes listener |

```js
const EventEmitter = require("events");
const event = new EventEmitter();

function orderHandler(id) {
  console.log("Order received:", id);
}

event.on("order", orderHandler);
event.once("start", () => console.log("Started once"));

event.emit("start");
event.emit("start");
event.emit("order", 101);

event.removeListener("order", orderHandler);
```

=> `start` executes only once because it is registered using `once()`.

## Q.5 (c) Differentiate `findOneAndReplace()` and `findOneAndUpdate()`. [07]

| `findOneAndReplace()` | `findOneAndUpdate()` |
|---|---|
| Replaces complete document except `_id` | Updates selected fields |
| Fields not included in replacement are removed | Other fields remain unchanged |
| Uses replacement document | Uses update operators like `$set` |
| Useful for complete document replacement | Useful for partial update |

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");
  await client.connect();
  const col = client.db("college").collection("students");

  await col.findOneAndUpdate(
    { rollno: 1 },
    { $set: { age: 21 } },
    { returnDocument: "after" }
  );

  await col.findOneAndReplace(
    { rollno: 1 },
    { rollno: 1, name: "Aman", branch: "CE" }
  );

  await client.close();
}

main();
```

=> Use `findOneAndUpdate()` when only some fields need change. Use `findOneAndReplace()` when the entire document should be replaced.
