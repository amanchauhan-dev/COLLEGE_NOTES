## Q.1 (a) What is DOM? State the usefulness of DOM in JavaScript. [03]

=> **DOM** stands for **Document Object Model**.

=> It represents an HTML page as a tree of objects.

### Usefulness

1. JavaScript can access HTML elements.

4. It helps handle events such as click, submit and keypress.


## Q.1 (c) What is MVC? Explain MVC with AngularJS example. [07]

=> **MVC** stands for **Model View Controller**.

=> It separates an application into three parts:

1. **Model**: Stores application data.
2. **View**: Displays data to user.
3. **Controller**: Connects model and view and contains logic.

### AngularJS MVC example

```html
<!DOCTYPE html>
<html ng-app="studentApp">
<body ng-controller="StudentCtrl">
  <h3>{{title}}</h3>
  Name: <input ng-model="student.name">
  <p>Welcome {{student.name}}</p>

  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script>
  var app = angular.module("studentApp", []);
  app.controller("StudentCtrl", function($scope) {
    $scope.title = "Student Application";
    $scope.student = { name: "Aman" };
  });
  </script>
</body>
</html>
```

=> Here `student` is model, HTML is view and `StudentCtrl` is controller.

## Q.2 (c) Explain AngularJS routing with example. [07]

=> Routing is used to create SPA navigation without reloading the full page.

### Steps

1. Include `angular-route.js`.
2. Create module with `ngRoute` dependency.
3. Configure routes using `$routeProvider`.
4. Use `ng-view` to display selected route.

```html
<html ng-app="app">
<body>
<a href="#!/">Home</a>
<a href="#!/contact">Contact</a>
<div ng-view></div>

<script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
<script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular-route.js"></script>
<script>
var app = angular.module("app", ["ngRoute"]);
app.config(function($routeProvider) {
  $routeProvider
    .when("/", { template: "<h2>Home</h2>" })
    .when("/contact", { template: "<h2>Contact</h2>" })
    .otherwise({ redirectTo: "/" });
});
</script>
</body>
</html>
```

## Q.3 (c OR) Node JS file upload in Uploads directory. [07]

```js
const http = require("http");
const formidable = require("formidable");
const fs = require("fs");
const path = require("path");

http.createServer((req, res) => {
  if (req.url === "/upload" && req.method === "POST") {
    const form = new formidable.IncomingForm();
    form.parse(req, (err, fields, files) => {
      const file = files.file[0] || files.file;
      const oldPath = file.filepath;
      const newPath = path.join(__dirname, "Uploads", file.originalFilename);
      fs.rename(oldPath, newPath, () => res.end("Uploaded"));
    });
  } else {
    res.end(`<form action="/upload" method="post" enctype="multipart/form-data">
      <input type="file" name="file"><button>Upload</button>
    </form>`);
  }
}).listen(8080);
```

=> Install `formidable` using `npm install formidable`.

## Q.4 (c OR) What is EventEmitter? Explain methods. [07]

=> `EventEmitter` is a class from `events` module used to create and handle custom events.

### Methods

1. `on(event, listener)`: Registers listener.
2. `emit(event, data)`: Fires event.
3. `once(event, listener)`: Executes listener only once.
4. `removeListener()`: Removes listener.

```js
const EventEmitter = require("events");
const e = new EventEmitter();

e.on("order", id => console.log("Order received:", id));
e.once("start", () => console.log("Started once"));

e.emit("start");
e.emit("start");
e.emit("order", 101);
```

## Q.5 (c) Differentiate `findOneAndReplace()` and `findOneAndUpdate()`. [07]

| `findOneAndReplace()` | `findOneAndUpdate()` |
|---|---|
| Replaces entire document except `_id` | Updates selected fields |
| Existing fields not in replacement are removed | Existing fields remain unchanged |
| Uses replacement document | Uses update operators like `$set` |

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");
  await client.connect();
  const col = client.db("college").collection("students");

  await col.findOneAndUpdate(
    { rollno: 1 },
    { $set: { name: "Raj", age: 21 } }
  );

  await col.findOneAndReplace(
    { rollno: 1 },
    { rollno: 1, name: "Rajesh", branch: "CE" }
  );

  await client.close();
}
main();
```

=> Use update when only some fields change. Use replace when complete document structure must be replaced.
