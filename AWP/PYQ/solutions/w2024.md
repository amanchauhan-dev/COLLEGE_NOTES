## Q.1 (a) What do you mean by responsive design? Explain with suitable example. [03]

=> **Responsive design** is a web design technique in which a webpage automatically adjusts its layout, images, font size and elements according to the screen size of the device.

=> It helps the same website work properly on desktop, tablet and mobile devices.

### Important points

1. It uses flexible layouts instead of fixed-width layouts.
2. It uses media queries to apply CSS based on screen width.
3. It uses the viewport meta tag for proper mobile scaling.
4. It improves user experience on all devices.

```html
<!DOCTYPE html>
<html>
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <style>
    .box {
      width: 50%;
      padding: 20px;
      background: lightblue;
      font-size: 20px;
    }

    @media (max-width: 600px) {
      .box {
        width: 100%;
        font-size: 16px;
      }
    }
  </style>
</head>
<body>
  <div class="box">Responsive Design Example</div>
</body>
</html>
```

=> On large screens the box takes 50% width, while on mobile screens it takes 100% width.

## Q.1 (b) Explain asynchronous programming in detail. [04]

=> **Asynchronous programming** is a programming approach where a task can start and the program can continue executing other statements without waiting for that task to finish.

=> It is useful for operations that take time, such as server requests, file reading, database operations and timers.

### Need of asynchronous programming

1. It prevents blocking of the main thread.
2. It improves performance and responsiveness.
3. It is useful for AJAX and API calls.
4. It allows multiple tasks to be handled efficiently.

```js
console.log("Start");

setTimeout(function() {
  console.log("Executed after 2 seconds");
}, 2000);

console.log("End");
```

### Output

```text
Start
End
Executed after 2 seconds
```

=> `setTimeout()` is asynchronous, so JavaScript does not wait for it. The next statement executes immediately.

## Q.1 (c) Explain the steps to implement routing using AngularJS with suitable example. [07]

=> **Routing** in AngularJS is used to create a **Single Page Application** where different views are loaded without refreshing the whole page.

=> AngularJS routing is implemented using the `ngRoute` module.

### Main components of routing

1. **`ngRoute` module**: Provides routing support.
2. **`$routeProvider`**: Defines URL paths and their templates/controllers.
3. **`ng-view` directive**: Displays the selected route view.
4. **Route links**: Used to navigate between views.

### Steps

1. Include AngularJS library.
2. Include `angular-route.js`.
3. Create AngularJS module with `ngRoute` dependency.
4. Configure routes using `$routeProvider`.
5. Add links using `#!`.
6. Add `<div ng-view></div>` where route content should display.

```html
<!DOCTYPE html>
<html ng-app="libraryApp">
<head>
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular-route.js"></script>
</head>
<body>
  <h2>Library Application</h2>

  <a href="#!/">Home</a> |
  <a href="#!/books">Books</a>

  <hr>
  <div ng-view></div>

  <script>
  var app = angular.module("libraryApp", ["ngRoute"]);

  app.config(function($routeProvider) {
    $routeProvider
      .when("/", {
        template: "<h3>Home Page</h3><p>Welcome to Library System.</p>"
      })
      .when("/books", {
        template: "<h3>Books Page</h3><p>Search and request books here.</p>"
      })
      .otherwise({
        redirectTo: "/"
      });
  });
  </script>
</body>
</html>
```

=> When the user clicks Books, only the content inside `ng-view` changes. The page does not reload completely.

## Q.2 (b) Explain various form validation states available in AngularJS. [04]

=> AngularJS provides built-in form validation states. These states help check whether form fields are valid, changed or touched by the user.

| State | Meaning |
|---|---|
| `$valid` | Field/form satisfies all validation rules |
| `$invalid` | Field/form fails one or more validation rules |
| `$pristine` | Field/form is not changed by user |
| `$dirty` | Field/form is changed by user |
| `$touched` | Field has been focused and then blurred |
| `$untouched` | Field is not yet touched by user |

```html
<form name="studentForm" ng-app="">
  <input name="email" type="email" ng-model="email" required>

  <p ng-show="studentForm.email.$touched && studentForm.email.$invalid">
    Enter valid email address.
  </p>

  <p>Valid: {{studentForm.email.$valid}}</p>
  <p>Dirty: {{studentForm.email.$dirty}}</p>
</form>
```

=> These validation states are useful for showing error messages only when the user interacts with a field.

## Q.2 (c) Define filter in AngularJS. Explain inbuilt filters. [07]

=> **Filter** in AngularJS is used to format the value of an expression before displaying it in the view.

=> Filters do not change the original model value. They only change how data appears on the page.

### Syntax

```html
{{ expression | filterName }}
```

### Common inbuilt filters

| Filter | Use | Example |
|---|---|---|
| `uppercase` | Converts string to uppercase | `{{name | uppercase}}` |
| `lowercase` | Converts string to lowercase | `{{name | lowercase}}` |
| `currency` | Formats number as currency | `{{price | currency}}` |
| `date` | Formats date | `{{today | date:'dd-MM-yyyy'}}` |
| `filter` | Filters array data | `ng-repeat="s in students | filter:q"` |
| `orderBy` | Sorts array data | `ng-repeat="s in students | orderBy:'name'"` |
| `limitTo` | Limits number of records/characters | `{{name | limitTo:3}}` |

```html
<!DOCTYPE html>
<html ng-app="">
<body ng-init="name='advanced web programming'; price=500; students=['Ravi','Aman','Neha']">
  <p>{{name | uppercase}}</p>
  <p>{{name | limitTo:8}}</p>
  <p>{{price | currency}}</p>

  Search: <input ng-model="q">
  <ul>
    <li ng-repeat="s in students | filter:q | orderBy:s">{{s}}</li>
  </ul>

  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
</body>
</html>
```

=> Filters make data readable and are commonly used in reports, tables and search lists.

### Advantages

## Q.3 (c OR) Print query string variables Email and Mobile using Node JS. [07]

```js
const http = require("http");
const url = require("url");

http.createServer(function(req, res) {

  res.writeHead(200, {"Content-Type": "text/html"});

  res.write("Mobile: " + query.Mobile);

  console.log("Server running on port 8080");
});
```

=> Open URL: `http://localhost:8080/?Email=xyz@gmail.com&Mobile=1234567890`.

=> `url.parse(req.url, true)` converts the query string into an object. Then values are accessed using `query.Email` and `query.Mobile`.

## Q.4 (c) Create Node JS server that writes visited pages in `log.txt`. [07]

```js
const http = require("http");
const fs = require("fs");

http.createServer(function(req, res) {
  const log = new Date().toISOString() + " - " + req.url + "\n";

  fs.appendFile("log.txt", log, function(err) {
    if (err) {
      res.writeHead(500, {"Content-Type": "text/plain"});
      res.end("Error writing log");
      return;
    }

    res.writeHead(200, {"Content-Type": "text/html"});
    res.end("<h3>Visited page: " + req.url + "</h3>");
  });
}).listen(8080, function() {
  console.log("Server running at http://localhost:8080");
});
```

=> `http` module creates the server and `fs.appendFile()` writes each visited URL into `log.txt`. It appends data instead of replacing old logs.

## Q.4 (c OR) Define stream in Node JS. Write code to read from stream. [07]

=> **Stream** is used to process data chunk by chunk instead of loading complete data into memory.

### Types of streams

1. **Readable stream**: Reads data.
2. **Writable stream**: Writes data.
3. **Duplex stream**: Reads and writes both.
4. **Transform stream**: Modifies data while reading/writing.

```js
const fs = require("fs");

const readStream = fs.createReadStream("data.txt", "utf8");
const writeStream = fs.createWriteStream("copy.txt");

readStream.on("data", function(chunk) {
  console.log("Chunk received:");
  console.log(chunk);
});

readStream.on("end", function() {
  console.log("Reading completed");
});

readStream.on("error", function(err) {
  console.log("Error:", err.message);
});

readStream.pipe(writeStream);
```

=> `pipe()` sends data from readable stream to writable stream. Streams are useful for large files because they save memory.

## Q.5 (c) MongoDB operations using `insertOne()`, `insertMany()`, `deleteOne()`, `deleteMany()`. [07]

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");

  try {
    await client.connect();
    const col = client.db("college").collection("students");

    await col.insertOne({ rollno: 1, name: "Aman" });

    await col.insertMany([
      { rollno: 2, name: "Ravi" },
      { rollno: 3, name: "Neha" }
    ]);

    await col.deleteOne({ rollno: 1 });
    await col.deleteMany({ name: "Ravi" });

    console.log("Operations completed");
  } catch (err) {
    console.log("Error:", err.message);
  } finally {
    await client.close();
  }
}

main();
```

=> `insertOne()` inserts one document, `insertMany()` inserts multiple documents, `deleteOne()` deletes first matching document and `deleteMany()` deletes all matching documents.

## Q.5 (c OR) Query Student collection in GTU database. [07]

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");

  try {
    await client.connect();
    const students = client.db("GTU").collection("Student");

    const ageResult = await students.find({
      age: { $gte: 20, $lte: 22 }
    }).toArray();

    const awpResult = await students.find({
      course: "AWP"
    }).toArray();

    console.log("Students age 20 to 22:", ageResult);
    console.log("Students with AWP course:", awpResult);
  } catch (err) {
    console.log("Error:", err.message);
  } finally {
    await client.close();
  }
}

main();
```

=> `$gte` means greater than or equal to and `$lte` means less than or equal to. `toArray()` converts cursor result into an array.
