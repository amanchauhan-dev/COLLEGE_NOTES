## Q.2 (c) Discuss error handling in JavaScript with example. [07]

=> Error handling is used to detect and handle runtime errors without stopping the whole program unexpectedly.

### Keywords

1. `try`: Contains code that may generate error.
2. `catch`: Handles the error.
3. `finally`: Executes whether error occurs or not.
4. `throw`: Creates custom error.

```js
try {
  let age = -5;

  if (age < 0) {
    throw new Error("Age cannot be negative");
  }

  console.log("Age:", age);
} catch (err) {
  console.log("Error:", err.message);
} finally {
  console.log("Validation completed");
}
```

=> Error handling improves reliability and user experience.

## Q.3 (c) Explain AngularJS events with suitable example. [07]

=> AngularJS provides event directives to handle user actions.

### Common event directives

| Directive | Use |
|---|---|
| `ng-click` | Executes on mouse click |
| `ng-dblclick` | Executes on double click |
| `ng-change` | Executes when input changes |
| `ng-focus` | Executes when input gets focus |
| `ng-blur` | Executes when input loses focus |

```html
<!DOCTYPE html>
<html ng-app="app">
<body ng-controller="Ctrl">
  <button ng-click="count = count + 1">Click</button>
  <input ng-model="name" ng-change="changed()" ng-blur="blurred()">
  <p>Count: {{count}}</p>
  <p>{{message}}</p>

  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script>
  var app = angular.module("app", []);
  app.controller("Ctrl", function($scope) {
    $scope.count = 0;
    $scope.changed = function() {
      $scope.message = "Input changed";
    };
    $scope.blurred = function() {
      $scope.message = "Input lost focus";
    };
  });
  </script>
</body>
</html>
```

## Q.4 (c) Write Node JS code to create a server. [07]

```js
const http = require("http");

const server = http.createServer(function(req, res) {
  res.writeHead(200, {"Content-Type": "text/html"});
  res.write("<h1>Hello from Node JS Server</h1>");
  res.end();
});

server.listen(8080, function() {
  console.log("Server running at http://localhost:8080");
});
```

=> `http.createServer()` creates server, `res.writeHead()` sets response header and `res.end()` ends response.

## Q.4 (c OR) What is stream? Write Node JS code to read from stream. [07]

=> Stream handles data in chunks instead of loading complete data into memory.

### Types

1. Readable.
2. Writable.
3. Duplex.
4. Transform.

```js
const fs = require("fs");

const stream = fs.createReadStream("data.txt", "utf8");

stream.on("data", function(chunk) {
  console.log("Chunk:", chunk);
});

stream.on("end", function() {
  console.log("Completed");
});

stream.on("error", function(err) {
  console.log("Error:", err.message);
});
```

## Q.5 (c) MongoDB connectivity with insert operation. [07]

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");

  try {
    await client.connect();
    const db = client.db("college");
    const students = db.collection("students");

    await students.insertOne({
      rollno: 1,
      name: "Aman",
      branch: "CE"
    });

    console.log("Document inserted");
  } catch (err) {
    console.log("Error:", err.message);
  } finally {
    await client.close();
  }
}

main();
```

=> Steps are connect MongoDB, select database, select collection and perform insert operation.

## Q.5 (c OR) Explain piping and chaining of streams with example. [07]

=> **Piping** sends output of one stream to another stream.

=> **Chaining** connects multiple stream operations together.

```js
const fs = require("fs");
const zlib = require("zlib");

fs.createReadStream("input.txt")
  .pipe(zlib.createGzip())
  .pipe(fs.createWriteStream("input.txt.gz"));
```

=> This program reads a file, compresses it using gzip and writes compressed output to a new file.

=> Piping and chaining are memory efficient for large files.
