## Q.2 (c) Error handling in JavaScript with example. [07]

=> Error handling manages runtime errors using `try`, `catch`, `finally` and `throw`.

```js
try {
  let age = -5;
  if (age < 0) {
    throw new Error("Age cannot be negative");
  }
  console.log(age);
} catch (err) {
  console.log("Error:", err.message);
} finally {
  console.log("Validation completed");
}
```

=> `try` contains risky code, `catch` handles error and `finally` always executes.

## Q.4 (c) Node JS code to create a server. [07]

```js
const http = require("http");

http.createServer((req, res) => {
  res.writeHead(200, {"Content-Type": "text/html"});
  res.end("<h1>Hello from Node JS Server</h1>");
}).listen(8080, () => {
  console.log("Server running at http://localhost:8080");
});
```

## Q.5 (c OR) Explain piping and chaining of streams with example. [07]

=> Piping connects output of one stream to input of another stream.

```js
const fs = require("fs");
const zlib = require("zlib");

fs.createReadStream("input.txt")
  .pipe(zlib.createGzip())
  .pipe(fs.createWriteStream("input.txt.gz"));
```

=> This is stream chaining. It is memory efficient and useful for large files.
