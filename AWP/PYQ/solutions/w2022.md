## Q.1 (b) JavaScript program to validate Email address. [04]

```html
<input id="email" placeholder="Email">
<button onclick="check()">Validate</button>
<p id="msg"></p>
<script>
function check() {
  let email = document.getElementById("email").value;
  let pattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  document.getElementById("msg").innerHTML =
    pattern.test(email) ? "Valid Email" : "Invalid Email";
}
</script>
```

## Q.2 (b) Explain data binding process in AngularJS. [04]

=> Data binding synchronizes model and view.

```html
<div ng-app="">
  <input ng-model="name">
  <p>{{name}}</p>
</div>
```

=> When the input changes, model changes. When model changes, view also updates.

## Q.2 (c) Explain controller in AngularJS with example. [07]

```html
<div ng-app="app" ng-controller="Ctrl">
  <h3>{{title}}</h3>
  <button ng-click="show()">Click</button>
</div>
<script>
var app = angular.module("app", []);
app.controller("Ctrl", function($scope) {
  $scope.title = "Controller Example";
  $scope.show = function() {
    alert("Hello");
  };
});
</script>
```

=> Controller contains view logic and initializes `$scope` variables/functions.

## Q.2 (c OR) Syntax to send HTTP POST request in AngularJS. [07]

```js
app.controller("Ctrl", function($scope, $http) {
  $scope.save = function() {
    $http.post("save.php", {
      name: $scope.name,
      email: $scope.email
    }).then(function(response) {
      $scope.msg = "Data saved";
    }, function(error) {
      $scope.msg = "Error occurred";
    });
  };
});
```

=> `$http.post()` sends data to server asynchronously.

## Q.3 (b) Differentiate AngularJS expressions and JavaScript expressions. [04]

| AngularJS Expression | JavaScript Expression |
|---|---|
| Written inside `{{ }}` | Written in script code |
| Does not support condition/loop statements | Supports full JS statements |
| Evaluated against Angular scope | Evaluated against global/local JS scope |
| Tolerates undefined/null | May throw error |

## Q.3 (c) What is `$rootScope` and how do we use it? [07]

=> `$rootScope` is the top-level scope available to the whole AngularJS application.

```html
<div ng-app="app" ng-controller="Ctrl">
  {{appName}}
</div>
<script>
var app = angular.module("app", []);
app.run(function($rootScope) {
  $rootScope.appName = "AWP App";
});
app.controller("Ctrl", function($scope) {});
</script>
```

=> It is useful for application-wide data, but overuse should be avoided.

## Q.3 (c OR) AngularJS code to check odd or even. [07]

## Q.5 (c OR) Update and delete Employee database using Node.js and MongoDB. [07]

```js
const { MongoClient } = require("mongodb");
async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");
  await client.connect();
  const emp = client.db("company").collection("employee");
  await emp.updateOne({ id: 1 }, { $set: { name: "Raj" } });
  await emp.deleteOne({ id: 2 });
  await client.close();
}
main();
```
