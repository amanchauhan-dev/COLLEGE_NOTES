## Q.1 (a) What is CSS? Explain the different types of CSS. [03]

=> **CSS** stands for **Cascading Style Sheets**.

=> CSS is used to control the presentation of HTML pages, such as color, font, spacing, border, layout and responsive design.

### Types of CSS

1. **Inline CSS**

=> Inline CSS is written inside an HTML tag using the `style` attribute.

```html
<p style="color: red; font-size: 18px;">Inline CSS Example</p>
```

2. **Internal CSS**

=> Internal CSS is written inside the `<style>` tag in the same HTML document.

```html
<style>
p {
  color: blue;
}
</style>
```

3. **External CSS**

=> External CSS is written in a separate `.css` file and linked with HTML.

```html
<link rel="stylesheet" href="style.css">
```

=> External CSS is best for large websites because the same stylesheet can be reused on many pages.

## Q.1 (b) Write a JavaScript program to validate an Email address. [04]

=> Email validation checks whether the entered email follows a proper format such as `name@example.com`.

=> In JavaScript, regular expression is commonly used for email validation.

```html
<!DOCTYPE html>
<html>
<body>
  <h3>Email Validation</h3>
  <input type="text" id="email" placeholder="Enter Email">
  <button onclick="validateEmail()">Validate</button>
  <p id="msg"></p>

  <script>
  function validateEmail() {
    var email = document.getElementById("email").value;
    var pattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

    if (pattern.test(email)) {
      document.getElementById("msg").innerHTML = "Valid Email";
    } else {
      document.getElementById("msg").innerHTML = "Invalid Email";
    }
  }
  </script>
</body>
</html>
```

=> `pattern.test(email)` returns true if the email matches the regular expression.

## Q.1 (c) What is SPA in AngularJS? Explain advantages of AngularJS. [07]

=> **SPA** stands for **Single Page Application**.

=> In SPA, only one main HTML page is loaded initially. After that, only required parts of the page are updated dynamically without full page reload.

=> AngularJS is useful for creating SPAs because it provides routing, data binding, directives and services.

### Working of SPA

```text
User clicks link
      |
AngularJS route changes
      |
Only view/template changes
      |
Complete page does not reload
```

### Advantages of AngularJS

1. **Two-way data binding**
=> Model and view are synchronized automatically.

2. **MVC architecture**
=> Application is divided into model, view and controller.

3. **Directives**
=> AngularJS extends HTML using directives like `ng-model`, `ng-repeat`, `ng-click`.

4. **Less DOM manipulation**
=> Developers do not need to manually update DOM repeatedly.

5. **Form validation**
=> AngularJS provides built-in validation states like `$valid`, `$invalid`, `$dirty`.

6. **Services**
=> Services like `$http` and `$timeout` provide reusable logic.

7. **Routing**
=> AngularJS can load multiple views in a single page application.

## Q.2 (c) Explain controller in AngularJS with example. [07]

=> **Controller** in AngularJS is a JavaScript function that controls data and behavior of a particular view.

=> Controller is connected to HTML using the `ng-controller` directive.

### Uses of controller

1. Initializes model data.
2. Defines functions used by the view.
3. Handles user actions.
4. Connects view with application logic.

```html
<!DOCTYPE html>
<html ng-app="studentApp">
<body ng-controller="StudentCtrl">
  <h3>{{title}}</h3>
  Name: <input ng-model="student.name">
  <button ng-click="show()">Show</button>
  <p>{{message}}</p>

  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script>
  var app = angular.module("studentApp", []);

  app.controller("StudentCtrl", function($scope) {
    $scope.title = "Student Controller Example";
    $scope.student = { name: "Aman" };

    $scope.show = function() {
      $scope.message = "Welcome " + $scope.student.name;
    };
  });
  </script>
</body>
</html>
```

=> `$scope` is used to share data between controller and view.

## Q.2 (c OR) Write syntax to send sample HTTP POST request in AngularJS. [07]

=> AngularJS provides `$http` service to send HTTP requests to server.

=> `POST` request is used to send data to server for insertion or processing.

```html
<div ng-app="app" ng-controller="Ctrl">
  <input ng-model="name" placeholder="Name">
  <input ng-model="email" placeholder="Email">
  <button ng-click="save()">Save</button>
  <p>{{msg}}</p>
</div>

<script>
var app = angular.module("app", []);
app.controller("Ctrl", function($scope, $http) {
  $scope.save = function() {
    var data = {
      name: $scope.name,
      email: $scope.email
    };

    $http.post("save.php", data).then(function(response) {
      $scope.msg = "Data sent successfully";
    }, function(error) {
      $scope.msg = "Error while sending data";
    });
  };
});
</script>
```

=> `$http.post(url, data)` sends data to server asynchronously and `then()` handles success or error response.

## Q.3 (c) What is `$rootScope` and how do we use it? [07]

=> `$rootScope` is the top-level scope in an AngularJS application.

=> Every AngularJS application has one `$rootScope`. All controller scopes are child scopes of `$rootScope`.

### Uses

1. Stores application-level data.
2. Shares common data between controllers.
3. Can store values like app name or logged-in username.

```html
<!DOCTYPE html>
<html ng-app="app">
<body>
  <div ng-controller="FirstCtrl">
    <h3>{{appName}}</h3>
    <p>{{message}}</p>
  </div>

  <div ng-controller="SecondCtrl">
    <h3>{{appName}}</h3>
    <p>{{subject}}</p>
  </div>

  <script src="https://ajax.googleapis.com/ajax/libs/angularjs/1.8.2/angular.min.js"></script>
  <script>
  var app = angular.module("app", []);

  app.run(function($rootScope) {
    $rootScope.appName = "AWP Application";
  });

  app.controller("FirstCtrl", function($scope) {
    $scope.message = "First Controller";
  });

  app.controller("SecondCtrl", function($scope) {
    $scope.subject = "Advanced Web Programming";
  });
  </script>
</body>
</html>
```

=> `$rootScope` should be used carefully because too much global data makes application difficult to maintain.

## Q.4 (c OR) Create a simple server in Node.js that returns Hello World. [07]

```js
const http = require("http");

const server = http.createServer(function(req, res) {
  res.writeHead(200, {"Content-Type": "text/html"});
  res.write("<h1>Hello World</h1>");
  res.end();
});

server.listen(8080, function() {
  console.log("Server running at http://localhost:8080");
});
```

=> `http.createServer()` creates a server. `res.writeHead()` sets response header and `res.end()` ends the response.

## Q.5 (c) Insert and find operations on Student database using Node.js and MongoDB. [07]

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");

  try {
    await client.connect();
    const db = client.db("college");
    const students = db.collection("students");

    await students.insertOne({
      rollno: 1,
      name: "Aman",
      branch: "CE"
    });

    const result = await students.find({}).toArray();
    console.log(result);
  } catch (err) {
    console.log("Error:", err.message);
  } finally {
    await client.close();
  }
}

main();
```

=> `insertOne()` inserts a new document and `find({})` returns all documents from the collection.

## Q.5 (a OR) Explain event-loop in Node.js. [03]

=> **Event loop** is the mechanism that allows Node.js to handle asynchronous operations without blocking the main thread.

=> When an asynchronous task completes, its callback is placed in a queue. Event loop picks callback from the queue and executes it.

```text
Call Stack -> Async Operation -> Callback Queue -> Event Loop -> Execution
```

## Q.5 (b OR) What is an error-first callback? [04]

=> Error-first callback is a common Node.js callback pattern where the first parameter is error and the second parameter is data/result.

```js
const fs = require("fs");

fs.readFile("data.txt", "utf8", function(err, data) {
  if (err) {
    console.log("Error:", err.message);
    return;
  }
  console.log(data);
});
```

=> If an error occurs, `err` contains error details. If no error occurs, `err` is `null`.

## Q.5 (c OR) Update and delete Employee database using Node.js and MongoDB. [07]

```js
const { MongoClient } = require("mongodb");

async function main() {
  const client = new MongoClient("mongodb://127.0.0.1:27017");

  try {
    await client.connect();
    const emp = client.db("company").collection("employee");

    await emp.updateOne(
      { emp_id: 1 },
      { $set: { name: "Raj", department: "IT" } }
    );

    await emp.deleteOne({ emp_id: 2 });

    console.log("Employee updated and deleted");
  } catch (err) {
    console.log("Error:", err.message);
  } finally {
    await client.close();
  }
}

main();
```

=> `updateOne()` updates first matching employee and `deleteOne()` deletes first matching employee.
