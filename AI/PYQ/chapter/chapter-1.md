## **Q.1 What is artificial intelligence? Define the different task domains of artificial intelligence. [07]**

### Repeated PYQ entries

```text
What is artificial intelligence? Define the different task domains of artificial intelligence.
[07] [3 Time] [Summer 2024]

OR

Define artificial intelligence. List the task domain of artificial intelligence with an example.
[03] [Summer 2023]

OR

What is artificial intelligence? Define the different task domains of artificial intelligence.
[03] [Summer 2022]
```

### Answer

=> **Definition**: `Artificial Intelligence (AI) is a branch of computer science that deals with creating machines or software systems that can perform tasks which normally require human intelligence.`

=> AI systems can reason, learn, solve problems, understand language, recognize patterns, plan actions and make decisions.

=> AI problems are commonly divided into three task domains.

### Task domains of AI

| Domain | Meaning | Examples |
|---|---|---|
| **Mundane tasks** | Common tasks humans do naturally | Vision, speech, natural language, common sense reasoning |
| **Formal tasks** | Rule-based symbolic or mathematical tasks | Chess, theorem proving, logic, puzzles |
| **Expert tasks** | Tasks requiring specialist knowledge | Medical diagnosis, engineering design, financial planning |

### 1. Mundane tasks

=> Mundane tasks are daily-life tasks that humans perform easily but machines find difficult because they need perception and common sense.

#### Examples

1. Recognizing objects in an image.
2. Understanding speech.
3. Reading handwriting.
4. Understanding natural language.
5. Moving safely in a room.

### 2. Formal tasks

=> Formal tasks have clear rules and can be represented using logic, symbols or state spaces.

#### Examples

1. Playing chess.
2. Solving 8-puzzle.
3. Proving mathematical theorems.
4. Solving logical problems.

### 3. Expert tasks

=> Expert tasks require domain-specific knowledge and decision-making ability similar to a human expert.

#### Examples

1. Medical diagnosis.
2. Machine fault diagnosis.
3. Mineral exploration.
4. Legal or financial advice.

=> Thus, AI covers ordinary perception-based tasks, formal rule-based tasks and expert-level decision-making tasks.

## **Q.2 Discuss various areas where Artificial Intelligence is used. [03]**

### Repeated PYQ entries

```text
OR

[03] [Winter 2024]

OR

[03] [Winter 2023]

OR

Discuss various areas where Artificial Intelligence is used.
[03] [Winter 2022]
```

### Answer

=> AI is used in many areas where machines need to reason, learn, recognize patterns or make decisions.

### Application areas

1. **Game playing**

=> AI is used in games such as chess and Go to search possible moves and select the best move.

=> Example: Deep Blue defeated world chess champion Garry Kasparov.

2. **Medical diagnosis**

=> AI analyzes symptoms, reports and medical images to support diagnosis.

=> Example: AI can help detect cancer from X-ray, CT or MRI images.

3. **Natural language processing**

=> AI helps computers understand and generate human language.

=> Example: chatbots, translation systems and grammar checkers.

4. **Speech recognition**

=> AI converts spoken words into text or commands.

=> Example: Siri, Google Assistant and voice typing.

5. **Computer vision**

=> AI identifies objects, faces and patterns in images and videos.

=> Example: face unlock, traffic sign detection and medical image analysis.

6. **Robotics**

=> AI helps robots sense the environment, plan movement and perform tasks.

=> Example: surgical robots and warehouse robots.

7. **Planning and scheduling**

=> AI creates a sequence of actions to complete a goal efficiently.

=> Example: airline scheduling, logistics planning and NASA space mission planning.

8. **Recommendation systems**

=> AI studies user behavior and recommends suitable items.

=> Example: movie, product and music recommendations.

### Area where AI can do better than humans

=> AI can do better than humans in **large data analysis** because it can process huge amounts of data quickly and find patterns that are difficult for humans to notice.

=> Example: An AI system can examine thousands of medical images quickly and highlight suspicious cases for doctors.

=> Thus, AI is useful in areas requiring speed, accuracy, automation and intelligent decision making.

## **Q.3 Explain AI problem characteristics in detail. [04]**

### Repeated PYQ entries

```text
Explain AI problem characteristics in detail.
[04] [2 Time] [Winter 2024]

OR

What are the AI problem characteristics? Discuss in detail with example.
[07] [Winter 2022]
```

### Answer

=> **AI problem characteristics** are the properties of a problem that help us decide which AI technique should be used to solve it.

=> Before solving an AI problem, we must study whether it is decomposable, predictable, recoverable, knowledge-intensive and interactive.

### Important AI problem characteristics

| Characteristic | Meaning | Example |
|---|---|---|
| **Decomposable** | Can be divided into smaller subproblems | Mathematical expression solving |
| **Ignorable steps** | Some steps can be ignored without affecting final solution | Theorem proving |
| **Recoverable steps** | Wrong step can be undone | 8-puzzle |
| **Irrecoverable steps** | Wrong step cannot be undone easily | Robot movement |
| **Predictable universe** | Result of action is known | Chess |
| **Unpredictable universe** | Result of action is uncertain | Medical diagnosis |
| **Good solution acceptable** | Approximate solution is enough | Route planning |
| **Optimal solution required** | Best solution is needed | Shortest path problem |
| **Knowledge intensive** | Requires large domain knowledge | Expert medical system |
| **Interactive** | Requires interaction with user/environment | Chatbot |

### 1. Is the problem decomposable?

=> If a problem can be divided into smaller independent subproblems, it becomes easier to solve.

=> Example: Solving a complex mathematical expression by solving its smaller parts.

### 2. Can solution steps be ignored or undone?

=> In some problems, wrong steps can be ignored or reversed.

=> Example: In the 8-puzzle, a tile move can be reversed.

=> In real-world robot movement, a wrong action may damage an object, so it may not be recoverable.

### 3. Is the universe predictable?

=> In a predictable problem, the result of each action is known.

=> Example: In chess, moving a piece has a fixed result according to rules.

=> In an unpredictable problem, the result is uncertain.

=> Example: In medical diagnosis, the same treatment may affect different patients differently.

### 4. Is a good solution enough?

=> Some AI problems do not require the perfect solution. A good practical solution is enough.

=> Example: A route planner may accept a near-shortest path if it is fast and avoids traffic.

=> Some problems need an optimal solution.

=> Example: Finding the exact shortest path in a graph.

### 5. Is the problem knowledge intensive?

=> Some problems require large expert knowledge to solve correctly.

=> Example: A medical expert system needs knowledge about diseases, symptoms, tests and medicines.

### 6. Does the problem require interaction?

=> Some systems must interact with a user or a changing environment.

=> Example: A chatbot must understand user input and respond immediately.

=> Thus, AI problem characteristics help in selecting suitable methods such as search, heuristics, knowledge representation, planning or learning.

## **Q.4 What is Turing Test? [03]**

### Repeated PYQ entries

```text
What is Turing test?
[03] [Summer 2024]
```

### Answer

=> **Turing Test** was proposed by Alan Turing in 1950 to test whether a machine can show intelligent behavior like a human.

=> In this test, a human judge communicates with a human and a machine through text messages.

=> If the judge cannot reliably identify which one is the machine, then the machine is considered intelligent.

### Diagram

```text
+------------------+
| Human Judge      |
+--------+---------+
         |
  Text conversation
         |
 +-------+--------+
 |                |
 v                v
Human          Machine
```

### Capabilities required

1. **Natural language processing**

=> To understand and reply in human language.

2. **Knowledge representation**

=> To store facts and information.

3. **Automated reasoning**

=> To draw conclusions and answer questions.

4. **Machine learning**

=> To improve from experience.

=> The **Total Turing Test** additionally requires computer vision and robotics so that the machine can perceive and manipulate objects.
