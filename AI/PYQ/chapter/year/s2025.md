## Q.1 (c) Explain the state space search with the use of 8 puzzle problem. [07]

=> **State space search** represents problem solving as movement from initial state to goal state.

### 8-puzzle

It has 8 numbered tiles and one blank space in a 3 x 3 board.

### State

Each board arrangement is a state.

```text
Initial state        Goal state
1 2 3                1 2 3
4 _ 6                4 5 6
7 5 8                7 8 _
```

### Operators

The blank tile can move:

1. Up
2. Down
3. Left
4. Right

### Search process

```text
Initial state
   |
Apply possible moves
   |
Generate successor states
   |
Check goal
   |
Continue until goal is reached
```

### Heuristics

1. Misplaced tiles
2. Manhattan distance

=> BFS, DFS, best-first search or A* can be used to solve it.

## Q.2 (a) Explain: Local maximum, Plateau, Ridge. [03]

1. **Local maximum**: a state better than its neighbors but not globally best.
2. **Plateau**: a flat area where all neighboring states have the same heuristic value.
3. **Ridge**: a narrow path where direct moves do not improve the heuristic.

=> These are common failure cases of hill climbing.

## Q.2 (c) What is Hill Climbing algorithm? Discuss the cases where Hill climbing fails. [07]

=> **Hill climbing** is a heuristic local search algorithm that repeatedly moves to a better neighboring state.

### Algorithm

```text
1. Start with initial state.
2. Evaluate current state.
3. Generate neighboring states.
4. Select a better neighbor.
5. If no better neighbor exists, stop.
6. Otherwise move to selected neighbor and repeat.
```

### Failure cases

1. **Local maximum**

=> The algorithm stops at a state better than neighbors but not the best solution.

2. **Plateau**

=> Neighboring states have the same value, so there is no clear direction.

3. **Ridge**

=> The solution path requires sideways or indirect moves.

### Limitations

1. Does not guarantee optimal solution.
2. Depends heavily on heuristic function.
3. May get stuck before reaching goal.

## Q.2 (c) OR Explain the A* search algorithm using an appropriate example. [07]

=> **A*** is an informed search algorithm that selects the node with minimum estimated total cost.

### Formula

```text
f(n) = g(n) + h(n)
```

Where `g(n)` is actual cost from start and `h(n)` is estimated cost to goal.

### Algorithm

```text
1. Put start node in OPEN.
2. Calculate f value.
3. Select node with minimum f.
4. If it is goal, return path.
5. Expand it and update successors.
6. Repeat.
```

### Example

```text
A -> B cost = 2, h(B)=4, f(B)=6
A -> C cost = 3, h(C)=2, f(C)=5
```

A* selects `C` first because its `f` value is lower.

### Properties

1. Complete if branching factor is finite.
2. Optimal when heuristic is admissible.
3. More efficient than uninformed search with good heuristic.

## Q.3 (a) Define Soundness and completeness in propositional logic. [03]

1. **Soundness**

=> An inference system is sound if every sentence it derives is logically true.

```text
If KB proves alpha, then KB entails alpha.
```

2. **Completeness**

=> An inference system is complete if it can derive every sentence that is logically entailed.

```text
If KB entails alpha, then KB can prove alpha.
```

## Q.3 (c) Explain Modus Ponens and Modus Tollens inference rules with example. [07]

### Modus Ponens

Rule:

```text
P
P -> Q
Therefore Q
```

Example:

```text
It is raining.
If it is raining, then road is wet.
Therefore, road is wet.
```

### Modus Tollens

Rule:

```text
P -> Q
not Q
Therefore not P
```

Example:

```text
If there is fire, then there is smoke.
There is no smoke.
Therefore, there is no fire.
```

### Difference

| Modus Ponens | Modus Tollens |
|---|---|
| Confirms consequent from antecedent. | Denies antecedent from denial of consequent. |
| Uses `P` and `P -> Q`. | Uses `not Q` and `P -> Q`. |

## Q.4 (c) Translate sentences and prove "West is criminal" using resolution. [07]

### Predicates

```text
American(x), Weapon(x), Sells(x,y,z), Hostile(x), Criminal(x)
Missile(x), Owns(x,y), Enemy(x, America)
```

### FOL representation

1. It is a crime for an American to sell weapons to hostile nations.

```text
American(x) and Weapon(y) and Sells(x,y,z) and Hostile(z) -> Criminal(x)
```

2. All missiles were sold to Nono by West.

```text
Missile(x) and Owns(Nono,x) -> Sells(West,x,Nono)
```

3. Nono is enemy of America.

```text
Enemy(Nono, America)
```

4. Enemy of America is hostile.

```text
Enemy(x, America) -> Hostile(x)
```

5. Nono has some missiles.

```text
exists x Missile(x) and Owns(Nono,x)
```

6. Missiles are weapons.

```text
Missile(x) -> Weapon(x)
```

7. West is American.

```text
American(West)
```

### Resolution proof

Let missile be `M1`.

```text
Missile(M1)
Owns(Nono, M1)
```

From rule 2:

```text
Sells(West, M1, Nono)
```

From missile rule:

```text
Weapon(M1)
```

From enemy rule:

```text
Hostile(Nono)
```

Given:

```text
American(West)
```

Using crime rule:

```text
Criminal(West)
```

=> Hence, **West is criminal**.

## Q.5 (c) Explain CUT, FAIL and REPEAT predicates in PROLOG. [07]

### Cut `!`

=> Cut prevents backtracking beyond that point.

```prolog
max(A, B, A) :-
    A >= B, !.
max(A, B, B).
```

### Fail

=> `fail` always fails and forces backtracking.

```prolog
print_all([H|T]) :-
    write(H), nl,
    fail.
print_all(_).
```

### Repeat

=> `repeat` always succeeds and is used to create loops.

```prolog
read_value :-
    repeat,
    read(X),
    write(X), nl,
    X = stop, !.
```

### Uses

1. Cut controls search.
2. Fail forces alternative solutions.
3. Repeat supports repeated execution.

## Q.5 (c) OR What is Wumpus world? Explain in detail. [07]

=> **Wumpus World** is a logical AI problem where an agent explores a cave to find gold while avoiding pits and a Wumpus.

### Environment

1. Grid of rooms.
2. Agent starts at initial square.
3. Some squares have pits.
4. One square has Wumpus.
5. One square has gold.

### Percepts

1. Breeze near a pit.
2. Stench near Wumpus.
3. Glitter near gold.
4. Bump near wall.
5. Scream when Wumpus dies.

### Actions

1. Move forward
2. Turn left
3. Turn right
4. Grab gold
5. Shoot arrow
6. Climb out

### Importance

=> It shows how a knowledge-based agent uses logical inference to decide safe moves.
