## Q.1 (b) Give an example of a problem for which breadth-first search would work better than depth-first search. [04]

=> BFS works better when the solution is shallow and the shortest path is required.

### Example

Finding the shortest path in an unweighted graph:

```text
A -> B -> Goal
A -> C -> D -> E -> Goal
```

BFS explores level by level, so it finds:

```text
A -> B -> Goal
```

DFS may go deep into `A -> C -> D -> E` before finding the goal.

### Reason

1. BFS is complete for finite branching.
2. BFS finds shortest path in terms of number of edges.
3. DFS may waste time in deep paths.

## Q.1 (c) Describe how branch-and-bound technique could be used to find the shortest solution to a water jug problem. [07]

=> **Branch and bound** explores possible solution paths but removes paths whose cost is already greater than the best solution found.

### State representation

For two jugs:

```text
(x, y)
```

Where `x` and `y` are current water quantities.

### Operators

1. Fill a jug
2. Empty a jug
3. Pour one jug into another

### Method

1. Start from initial state `(0,0)`.
2. Generate all possible next states.
3. Assign path cost, usually number of steps.
4. Expand the state with least cost.
5. If a path cost exceeds current best solution, discard it.
6. Stop when goal state is reached with minimum cost.

### Example

For 8-liter and 5-liter jugs:

```text
Goal: get 4 liters in 8-liter jug
```

One solution path:

```text
(0,0) -> (0,5) -> (5,0) -> (5,5) -> (8,2)
-> (0,2) -> (2,0) -> (2,5) -> (7,0)
-> (7,5) -> (8,4) -> (0,4) -> (4,0)
```

=> Branch and bound guarantees shortest solution if path cost is handled correctly.

## Q.3 (a) Convert `P <=> (Q v R)` to conjunctive normal form. [03]

```text
P <-> (Q or R)
```

Remove biconditional:

```text
(P -> (Q or R)) and ((Q or R) -> P)
```

Remove implication:

```text
(not P or Q or R) and (not(Q or R) or P)
```

Apply De Morgan and distribute:

```text
(not P or Q or R) and (P or not Q) and (P or not R)
```

## Q.3 (b) What is Hill Climbing algorithm? Discuss any two cases where Hill climbing fails. [04]

=> Hill climbing is a heuristic local search algorithm that moves from current state to a better neighbor.

### Algorithm

```text
1. Start with initial state.
2. Generate neighbors.
3. Move to better neighbor.
4. Stop if no better neighbor exists.
```

### Failure cases

1. **Local maximum**: better than neighbors but not global best.
2. **Plateau**: all neighboring states have same value.
3. **Ridge**: improvement requires indirect moves.

## Q.3 (c) Explain the AO* algorithm with an example. [07]

=> **AO*** is a heuristic search algorithm used for AND-OR graphs.

### AND-OR graph

1. **OR node**: any one child can solve the problem.
2. **AND node**: all child nodes must be solved.

### Algorithm

```text
1. Start from initial node.
2. Select most promising unsolved node.
3. Expand it.
4. Calculate cost using heuristic values.
5. For OR node, choose minimum cost child.
6. For AND node, add costs of all required children.
7. Propagate updated cost backward.
8. Stop when start node is solved.
```

### Example

```text
        A
      /   \
     B     C
   AND     OR
   / \    /  \
  D   E  F    G
```

If:

```text
Cost(B) = Cost(D) + Cost(E)
Cost(C) = min(Cost(F), Cost(G))
```

Then:

```text
Cost(A) = min(Cost(B), Cost(C))
```

=> AO* selects the minimum cost solution subgraph.

## Q.3 (c) OR Discuss Best-First search method with example. [07]

=> **Best-first search** expands the node that appears closest to the goal according to a heuristic.

### Algorithm

```text
1. Put start node in OPEN.
2. Select node with best heuristic value.
3. If it is goal, stop.
4. Expand selected node.
5. Add successors to OPEN.
6. Move selected node to CLOSED.
7. Repeat.
```

### Example

```text
From A:
B has h=8
C has h=3
D has h=6
```

Best-first search selects `C` first because it has lowest heuristic value.

### Advantages

1. Uses domain knowledge.
2. Can reduce search time.
3. Useful in route finding and puzzle solving.

### Limitation

=> It may not always find optimal path because it depends on heuristic value.

## Q.4 (c) Explain alpha-beta pruning in Minimax procedure for game playing with example. [07]

=> **Alpha-beta pruning** removes branches in minimax that cannot affect the final decision.

### Terms

1. `Alpha`: best value for MAX so far.
2. `Beta`: best value for MIN so far.

### Cutoff

```text
if alpha >= beta, stop exploring that branch
```

### Example

```text
          MAX
        /     \
      MIN     MIN
     /  \     /  \
    3    5   2    9
```

Left MIN returns:

```text
min(3,5) = 3
```

At root, alpha becomes 3.

In right MIN node, first child is 2. Since MIN can already give 2, MAX will not choose this branch because `2 < alpha`.

So remaining child 9 can be pruned.

=> Alpha-beta gives same result as minimax but with fewer node evaluations.

## Q.4 (b) OR Factors determining forward or backward problem-solving search direction. [04]

### Use forward search when

1. Initial state is clearly known.
2. There are few possible actions from each state.
3. Many possible goals exist.
4. We need to derive all possible conclusions.

### Use backward search when

1. Goal state is clearly known.
2. There are many initial facts but few goals.
3. We only need to prove one query.
4. Goal has limited possible predecessor states.

## Q.4 (c) OR Explain Minimax procedure for game playing with example. [07]

=> **Minimax** is used in two-player games where MAX tries to maximize utility and MIN tries to minimize it.

### Algorithm

```text
1. Generate game tree.
2. Evaluate leaf nodes.
3. At MAX node, choose maximum value.
4. At MIN node, choose minimum value.
5. Back up values to root.
```

### Example

```text
          MAX
        /     \
      MIN     MIN
     /  \     /  \
    6    4   8    3
```

MIN level:

```text
min(6,4)=4
min(8,3)=3
```

MAX level:

```text
max(4,3)=4
```

=> MAX chooses the left branch.
